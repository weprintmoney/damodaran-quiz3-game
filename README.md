# Doubt Everything

A study game for Module 3 (lessons 20–26) of Applied Corporate Finance. The questions come from Aswath Damodaran's publicly posted past quizzes and exams, sorted into the online course's lesson order. Every answer, right or wrong, comes with an explanation. A chapter unlocks only after every question in the previous one has been answered correctly.

Play: https://weprintmoney.github.io/damodaran-quiz3-game/

- `questions.json`: the question bank. Each question records the lesson it tests and its professor source: a past paper (`source`) or a lecture example or review sheet (`basis`).
- `tools/check_questions.py`: validates lesson alignment, professor sourcing, and chapter coverage. Run it before every push.
- Progress is stored in your browser only.
